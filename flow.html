실데이터 미연결

이 페이지의 화면과 표 구조는 준비되어 있습니다. 다만 기존 STOCK INSIGHT PRO에서 사용 중인 네이버 종목정보 프록시는 KRX 투자자별 거래실적·프로그램 매매·선물 수급 API가 아닙니다. 정확한 실데이터를 연결하려면 별도 데이터 공급 경로가 필요합니다.

  • KRX 정보데이터시스템: 투자자별 거래실적, 프로그램 매매, 지수·선물 통계 확인
  • 자동 수집: KRX 데이터 요청 규격에 맞춘 서버 프록시 또는 증권사 데이터 API 필요
  • 선물 금액과 계약 수는 각각 원천 데이터의 단위를 확인한 뒤 표시
